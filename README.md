# 🛍️ Dordouneh E-Commerce

**A Persian RTL E-Commerce Web Application built with HTML, CSS, and JavaScript.**

Dordouneh is a front-end e-commerce project designed to demonstrate practical web development skills through a complete shopping experience, including product discovery, filtering, product details, cart management, checkout flow, and order history.

---

## 🌐 Overview

Dordouneh is inspired by modern e-commerce platforms and built with a focus on:

* Clean and modular front-end structure
* Persian and RTL user experience
* Dynamic product rendering
* Search and category filtering
* Shopping cart management
* Client-side data persistence
* Multi-page e-commerce workflow

The project is developed using **vanilla JavaScript**, without relying on a front-end framework.

---

## ✨ Features

### 🔎 Product Discovery

* Product listing
* Product search
* Category filtering
* Discount filtering
* Product details
* Product ratings
* Product images and descriptions

### 🛒 Shopping Cart

* Add products to cart
* Increase/decrease quantities
* Remove products
* Automatic total calculation
* Persistent cart data using `localStorage`

### 👤 User & Order Flow

* Login interface
* Registration interface
* Checkout workflow
* Payment interface
* Order history
* Order success page

> Authentication and payment are currently implemented as front-end interfaces. A secure backend authentication system and real payment gateway can be integrated in future versions.

## 🧩 Architecture

The project follows a modular multi-page structure.

JavaScript functionality is separated into dedicated files for different parts of the application, including:

* Product management
* Search and filtering
* Authentication interface
* Shopping cart
* Product details
* Checkout
* Payment
* Orders
* Header and banner functionality

This structure makes the project easier to maintain and extend.
